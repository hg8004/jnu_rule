# 실습 P7 · 전남대학교 학사 규정 RAG 챗봇 — 결과물

신소재공학부 「인공지능재료공학」(MSE9115) 실습 P7에서 만든 결과물입니다.
전남대학교 학사 규정 5종을 검색해서 답하는 챗봇을 만들고, **검색층과 생성층을 갈라서** 쟀습니다.

> **전남대학교의 공식 서비스가 아닙니다.** 이 챗봇의 답으로 학사 판단을 하지 마십시오.
> 규정은 개정되며, 여기 쓴 것은 특정 시점의 사본입니다. 학칙은 들어 있지 않습니다.

- **챗봇 바로 열기**: https://hg8004.github.io/jnu_rule/ (자신의 TimelyGPT API 키가 필요합니다)
- 이 폴더에는 **제가 만든 결과물만** 있습니다. 실습 안내서·정답 키·채점기 같은 수업 자료는 올리지 않았습니다.

## 잰 것 — 요약

- **청킹**: 500자 고정은 조각의 **46%(35/76)가 조문 중간에서** 끊기고, 「다만」 단서가 4곳에서 갈라졌습니다.
  관문 10문항에서 조 단위는 **10/10**, 500자는 **8/10**이 상위 5위 안에 들었습니다.
- **검색 × 답 (19문항, k=5)**

  | | 답 O | 답 X |
  |---|---|---|
  | 검색 O | 13 | 1 |
  | 검색 X | 4 | 1 |

  빠진 정답 조각은 #6·#11·#12·#15·#16위였습니다. 다섯 중 넷이 근거 조항이 둘 이상인 문항이었고,
  나머지 하나(#6)는 「확인할 수 없다」가 정답인 문항이었습니다.
  **k를 8로 올려도 #6 하나만 들어오고, 근거가 둘 이상인 문항의 조각은 여전히 빠집니다.**
- **인용 검증**: 실패로 표시된 54건을 손으로 대조했더니 **위조는 0건**이었습니다(37건은 채점기의 추출 오류).
  반대로 진짜 문제(판본 오기, 반쪽 근거)는 이 검사에 걸리지 않았습니다.
- **주입**: 메모 형식의 거짓은 **검색 1위**였지만 모델이 기각했고, 개정 공고 형식의 거짓은 **검색 2위**였는데
  채택됐습니다. **검색층과 생성층이 반대로 갈렸고, 답을 정한 것은 내용이 아니라 규정처럼 보이는 형식이었습니다.**
