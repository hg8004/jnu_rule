# 응답 원문

API 응답을 **자르지 말고 통째로** 여기에 저장합니다.
벡터는 1,536개 숫자입니다. 길다고 요약하지 마십시오.

`answers.json` 은 채점기의 입력입니다. 이 모양이어야 합니다.

```json
{"M01": {"answer": "…모델의 답 전문…",
         "hits":   ["01_교학규정::제50조", "…"]},
 "M02": {"answer": "…", "hits": ["…"]}}
```

`hits` 는 **그 질문에서 문맥에 실제로 넣은 조각의 id** 입니다.
이것이 없으면 검색층을 채점할 수 없습니다.

> **요청 헤더를 저장하지 마십시오. 키가 그 안에 있습니다.**
